v1.0 Architecture

Layout Architecture Guide

The KV Renderer translates an abstract JSON schema into a high-fidelity, coordinate-based canvas. It supports dynamic text mapping, arbitrary shapes, multiple images, and direct exports to PNG or WebP.

Root Configuration

Property Type Description
width / height number Canvas dimensions. Default is 1920x1080, but our standard templates are built for 1280x720.
background string Hex color for the base slide layer. Overrides theme background.
theme Object | string Defines standard palette (primaryColor, textColor, accentColor). Fallback text/accent colors pull from here.

Rendering Order (Z-Index)

The KV Renderer uses the painter's algorithm. Elements pushed to the canvas first appear at the bottom, while subsequent elements are drawn on top. Understanding this sequence is critical for layering shapes, text, and images correctly.

Layer Schema Key Description
1 background Absolute base layer covering the entire canvas.
2 shapes Renders directly over the background. Perfect for decorative accents, drop-shadow cards, and watermarks.
3 title, description Core slide typography.
4 keyPoints List containers, bullets, and body text.
5 table Data grids and row backgrounds.
6 codeBlock Editor background box and monospace text.
7 image, images Media elements overlaying any of the content blocks above.
8 texts Floating text boxes (captions, labels, annotations). Deliberately rendered over images for overlay effects.
9 logo Header branding element. Renders above almost everything else to avoid clipping.
10 footer Absolute foreground. Ensures slide metadata is never obscured.

Custom Fonts

Because the renderer runs in the backend, it cannot download web fonts (like Google Fonts) on the fly. Fonts must be physically preloaded into the server environment before they can be used in your JSON schemas.

Contact your system administrator
1. provide the `.ttf` or `.otf` font files to store on the server.
2. provide a JSON array to specify the following: 

[
  {
    "path": "Poppins-Regular.ttf",
    "family": "Poppins",
    "weight": "normal",
    "style": "normal"
  },
  {
    "path": "Poppins-Bold.ttf",
    "family": "Poppins",
    "weight": "bold",
    "style": "normal"
  }
]

Note: If you request a fontFamily in your JSON that hasn't been registered by the admin, the renderer will silently fall back to standard system fonts (Arial, Times, etc.).

Title & Description

The primary text hierarchy. Always constrained by a specific width to ensure text wraps properly instead of running off the slide.

Property Type Description
text string The actual text content to render.
x, y number Top-left coordinates of the bounding box.
width number Maximum width before text wraps to a new line.
fontSize, fontFamily number/string Typography styling (e.g., "Arial", 46).
fontStyle string Accepts "normal", "bold", or "italic".
color / fill string Text color (hex code). Both keys map to the fill attribute. 
"title": {
  "text": "Slide Main Heading",
  "x": 70, // Start margin
  "y": 65,
  "width": 620, // Limit width for wrapping
  "fontSize": 46,
  "fontFamily": "Georgia",
  "color": "#1B3B2B"
},
"description": {
  "text": "Supporting context text.",
  "x": 70,
  "y": 165, // Note the 100px gap from Title
  "fontSize": 24
}

Key Points

Can be rendered in two ways depending on the data structure: as stacked Numbered Cards (if array of strings) or a Compact Bulleted Box (if passed as a structured object). Spacing and line heights are computed dynamically based on the font size.

Property Type Description
items Array Array of strings, or objects with {text: "..."}.
title string Optional header text for the bullet box.
fontSize, color number/string Applied to all bullet items (placed at root or in style).
style.boxBackground string Draws a colored rounded rectangle behind the list.
style.bulletColor string Color of the circular bullet points.

Detailed specification of key points

Requires a structured object with an items array. Draws a background container.

"keyPoints": {
  "x": 70, "y": 350,
  "title": "Core Pillars",
  "fontSize": 22,
  "items": [
    "Bullet point one",
    "Bullet point two"
  ],
  "style": {
    "bulletColor": "#E07A5F",
    "boxBackground": "#EDF4E0"
  }
}

Simple listing of key points

Pass an array directly. Draws individual dark slate numbered cards for each item.

"keyPoints": [
  "First major takeaway.",
  "Second major takeaway.",
  "Third point goes here."
]

Media (Images & Logo)

The renderer natively supports single images, plural images arrays, and an isolated brand logo. Auto-stacking layout: If multiple URLs are passed without coordinates, the engine stacks them cleanly down the right-hand column.

Property Type Description
url / src string Remote URL or local path to image (.png, .jpg, .webp).
x, y number Position. (Defaults to top-right layout).
width, height number Image dimensions.
cornerRadius number Rounds edges (can be placed at root or inside style). 
"logo": {
  "url": "https://images.unsplash.com/photo-...",
  "x": 1180, // Top Right alignment calculation
  "y": 40,
  "width": 30,
  "height": 30,
  "style": { "cornerRadius": 15 } // Circular
},
"images": [
  {
    "url": "https://images.unsplash.com/photo-...",
    "x": 740, // Starts past the center gutter
    "y": 55,
    "width": 470,
    "height": 280,
    "cornerRadius": 20
  }
]

Decorative Shapes (shapes)

Shapes render at Z-Index 1 (immediately over the background, behind all text and images). Use them for accent lines, stat-card backdrops, or subtle background geometry.

Property Type Description
type string 'Rect', 'Circle', 'Ellipse', or 'Line'.
x, y number Position. Center-point for Circles; Top-left for Rects.
width, height number Required for Rects.
radius number Required for Circles (replaces width/height).
points number[] Required for Lines [x1, y1, x2, y2].
fill / stroke string Background color / Outline border color.
shadowBlur number Drop shadow spread (pairs with shadowColor). 
"shapes": [
  {
    // 1. Left Edge Accent Ribbon
    "type": "Rect",
    "x": 0, "y": 0, "width": 16, "height": 720,
    "fill": "#E07A5F"
  },
  {
    // 2. Concentric emblem (rendered behind top-right logo)
    "type": "Circle",
    "x": 1195, "y": 55, // Coordinates define CENTER point
    "radius": 28,
    "fill": "#EDF4E0"
  },
  {
    // 3. Custom divider line
    "type": "Line",
    "points": [70, 240, 650, 240], // [x1, y1, x2, y2]
    "stroke": "#8DAA91",
    "strokeWidth": 2
  }
]

Text Boxes (texts)

The texts array allows you to place arbitrary typographic elements anywhere on the canvas. These render at a high Z-Index, making them perfect for Image Captions, Hero Metric Stats, or labels layered over shapes.

Property Type Description
text string Content (supports line breaks).
x, y number Top-left absolute positioning.
width number Forces text wrapping if content exceeds width.
fontSize, color number/string Typography styles.
align string 'left', 'center', or 'right' (requires width). 
"texts": [
  {
    "text": "4.5x",
    "x": 110, "y": 380,
    "fontSize": 44,
    "fontStyle": "bold",
    "color": "#38BDF8"
  },
  {
    "text": "Fig 1.1: Image Caption under photo",
    "x": 700, "y": 515,
    "width": 510,
    "fontSize": 15,
    "fontStyle": "italic",
    "color": "#64748B"
  }
]

Tables (table)

Renders a structured data grid with automatic column distribution, custom padding, and alternating row background colors.

Property Type Description
headers string[] Array of column title strings.
rows string[][] Array of rows, where each row is an array of cell strings.
x, y, width, height number Overall bounding box (columns divide evenly into width).
style.headerBackground string Hex color for the top header row.
style.alternateRowBackground string Hex color for zebra-striping rows. 
"table": {
  "x": 70, "y": 230,
  "width": 1140, "height": 360,
  "headers": ["Metric", "Q1 2026", "Q2 2026", "YoY Growth"],
  "rows": [
    ["Revenue", "$1.2M", "$1.5M", "+25%"],
    ["Active Users", "45,000", "52,000", "+15%"]
  ],
  "style": {
    "headerBackground": "#0EA5E9",
    "headerTextColor": "#FFFFFF",
    "rowBackground": "#F8FAFC",
    "alternateRowBackground": "#EEF5FB",
    "borderColor": "#E2E8F0",
    "cornerRadius": 8
  }
}

Code Blocks (codeBlock)

Renders a beautifully styled, rounded editor background box with monospace text inside. Perfect for technical presentations or software architecture slides.

Property Type Description
code string Raw code string (use \n for line breaks).
x, y, width, height number Outer bounds of the editor background box.
style.background string Editor canvas color (defaults to dark slate).
style.textColor string Code font color (defaults to light gray).
style.padding number Inner text inset (defaults to 24px). 
"codeBlock": {
  "code": "function render() {\n  console.log('Building layout...');\n}",
  "x": 760,
  "y": 190,
  "width": 450,
  "height": 300,
  "style": {
    "background": "#0F172A",
    "textColor": "#E2E8F0",
    "fontFamily": "Consolas, monospace",
    "fontSize": 20,
    "padding": 24,
    "cornerRadius": 12
  }
}

Footer Metadata (footer)

Renders at the highest Z-Index at the absolute bottom of the canvas (default y: height - 60). Use this for slide numbers, copyright strings, or presentation titles.

Property Type Description
text string Metadata string.
x, y number Defaults to bottom-left layout (x: 140, y: height-60).
fontSize, color number/string Typography styles. 
"footer": {
  "text": "Confidential & Proprietary 2026",
  "x": 140, // Matches the default left margin
  "y": 660, // For a 720px high canvas
  "fontSize": 16,
  "color": "#64748B"
}
